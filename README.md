# Meta Ads Client

Client Node.js untuk mengelola kampanye iklan Meta (Facebook & Instagram) khusus untuk toko online Shopee dan TikTok.

## Instalasi

```bash
cp .env.example .env
npm install
```

Isi `.env` dengan token dan ID akun ads Anda.

## Penggunaan

```bash
npm start
```

## Fitur

- Autentikasi & validasi access token Meta
- Manajemen kampanye, adset, dan kreatif iklan
- Reporting insights (CPC, CTR, spend)
